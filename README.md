# Rocq-Agent-for-MK

This repository contains the source code and generated formalization files for the paper:

**"Design of a Rocq Intelligent Agent for the Formalization of Morse–Kelley Axiomatic Set Theory"**

The repository provides the implementation of a large language model (LLM)-based Rocq intelligent agent and the corresponding Rocq proof files generated during the formalization of Morse–Kelley (MK) axiomatic set theory.
